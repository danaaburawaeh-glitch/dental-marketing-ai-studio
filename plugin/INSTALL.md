# INSTALL — دليل التثبيت لأول تشغيلة

هذا الدليل لمستخدم جديد فتح `Dental-Marketing-AI-Studio-Latest.zip` لأول
مرة، بلا أي علاقة بحساب مُنشئ الحزمة الأصلي. لا خطوة هنا تحتاج مساعداً أو
Skill أو ملف معرفة من حساب آخر — الحزمة مستقلة بالكامل
(`governance/standalone-guarantee.md`، `DEPENDENCIES.md`).

## 1. ثبّتي الإضافة

فكّي `Dental-Marketing-AI-Studio-Latest.zip` وثبّتيها في Cowork كإضافة
(Plugin) عادية. لا حساب خارجي، لا مفتاح API، لا اشتراك مطلوب لأي قدرة
أساسية.

## 2. عبّئي بيانات عيادتك — نقطة التخصيص الوحيدة

افتحي `identity/house-rules.md §١` واملئي الحقول المعلَّمة `⟨...⟩`: اسم
العيادة/التخصص، المدينة، النبرة، الكلمات الممنوعة، روابط التواصل (اختياري).
كل مهارة من الـ21 ترث هذه البيانات تلقائياً عبر `policy_dependencies:
[house-rules]` — لا حاجة لفتح أي ملف `SKILL.md` بنفسك.

**لا تعدّلي أي حقل آخر في هذا الملف** إلا إذا كنتِ تعرفين تحديداً ماذا
تفعلين — بقية الملف قواعد نزاهة محتوى تنطبق على كل مساعد ولا يُفترض
تخصيصها لكل عيادة.

## 3. اقرئي حدود النظام مرة واحدة

- `identity/clinical-firewall.md` — متى يتوقف أي مساعد كلياً ويُحيلك لموعد
  كشف. هذا القرار **لا يُعطَّل أبداً**، بأي صياغة طلب.
- `governance/scope-boundary.md` — ما الذي تفعله هذه الإضافة (إدارة عيادة
  وتسويق) وما لا تفعله أبداً (أي قرار سريري: تشخيص، خطة علاج، تفسير أشعة).

## 4. (اختياري) وصّلي التكاملات الخارجية

كل تكامل هنا **اختياري تماماً** — النظام يعمل بكامل قدراته الأساسية بدونه،
عبر Manual Execution Mode (تحليل + توصية + مخرَج جاهز للنسخ اليدوي + الخطوة
التالية). لا حاجة لأي `.env` أو مفتاح API يدوي — التكاملات تُدار عبر
موصّلات (Connectors) منصة Cowork نفسها:

| إن أردتِ | صِلي |
|---|---|
| قراءة/رد آلي على واتساب وInstagram DM | ChatPlace |
| مقاييس حملات حية | Meta Ads |
| تحليلات عبر منصات متعددة | Windsor.ai |
| توليد أصول بصرية جاهزة | Canva |
| حفظ/جدولة عبر أدوات جوجل | Google Drive / Calendar |

الجدول الكامل بكل تكامل ومهاراته والسلوك عند غيابه: `DEPENDENCIES.md` §
Optional integrations، و`governance/capability-detection.md`. مرجع سريع
للتنسيقات: `config.example`.

## 5. جرّبيها

قولي لأي مما يلي:

- «وش المساعدين عندي؟» — تعرض الدليل الكامل.
- «ابني لي مساعد …» — تبدأ مقابلة بناء مساعد مخصص.
- «أنشئ خطة تسويقية كاملة لـ…» — `marketing-strategy-planner`.
- «أنشئ تقويم محتوى أسبوعي» — `content-social-calendar-scheduler`.
- «اكتب سيناريو إغلاق ليد متردد» — `content-whatsapp-lead-responder`.

الجرد الكامل لكل مهارة وعبارات تشغيلها في `SKILLS-INVENTORY.md`.

## 6. (اختياري، لمن يريد التحقق بنفسه) شغّلي فحوص الحوكمة

يحتاج بيئة تشغّل Python 3؛ غير مطلوب لاستخدام الإضافة نفسها من داخل Claude:

```bash
python3 scripts/validate_system.py --skills skills \
       --policy identity/house-rules.md --policy identity/clinical-firewall.md
python3 scripts/routing_tests.py --skills skills --tests governance/routing-tests.yaml
python3 tests/standalone/test_standalone.py --skills skills
python3 tests/dependency-scan.py --root .
```

النتائج المرجعية الكاملة (كيف يجب أن تبدو تشغيلة نظيفة) في
`RELEASE-AUDIT-v1.4.1.md`.

## ماذا لو احتجتِ شيئاً تعتقدين أن الاستوديو لا يغطّيه؟

قولي «ابني لي مساعد …» — `system-assistant-builder` يبني مهارة مخصصة جديدة
من مقابلة قصيرة، ملتزمة بنفس المخطط والحوكمة تلقائياً. لا حاجة لتحرير أي
ملف يدوياً.

## استكشاف الأخطاء

| العرض | السبب المحتمل | الحل |
|---|---|---|
| مهارة لا تُستدعى رغم أنها مذكورة في `SKILLS-INVENTORY.md` | حالتها `TESTING`/`DRAFT` — لا تدخل التوجيه بتصميم النظام | تحققي من `metadata.status` في `SKILL.md` الخاص بها |
| طلب سريري لم يُرفَض بوضوح | نادر — الجدار السريري يعمل قبل التوجيه دائماً | تحققي من `identity/clinical-firewall.md`؛ أبلغي عبر القناة المعتادة إن تكرر |
| تكامل خارجي (واتساب مثلاً) لا يعمل | التكامل غير مفعَّل بعد أو الاتصال منقطع | النظام يستمر تلقائياً بـManual Execution Mode — راجعي `governance/capability-detection.md`؛ فعّلي الموصّل من إعدادات Cowork عند الحاجة |
