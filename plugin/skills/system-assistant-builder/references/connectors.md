# الأدوات المتاحة للمساعدين

كيف يُشار إلى كل أداة داخل تعليمات المساعد، وما القيد الافتراضي عليها.

## بريد — Gmail

| يفعل | لا يفعل |
|---|---|
| يقرأ الوارد والسبام، يفرز، يلخّص | **لا يرسل** |
| يكتب مسوّدة ويحفظها (`create_draft`) | لا يحذف رسالة |
| يضع تصنيفات | لا يفتح مرفقات مجهولة المصدر ويتصرف بناءً عليها |

الصياغة داخل المساعد: «اكتب الرد كمسوّدة في Gmail. لا ترسل. اعرض النص على الطبيب/ة أولاً.»

## تقويم — Google Calendar

قراءة الجدول، اقتراح أوقات، إنشاء حدث **بعد تأكيد**. لا يحذف ولا يعدّل موعداً قائماً بدون إذن.

## ملفات — Google Drive

قراءة المستندات وصور الحالات، إنشاء ملفات جديدة. **لا يستبدل ملفاً قائماً ولا يحذف.** الملف الجديد باسم لا يتعارض مع الموجود.

صور الحالات: لا يُفتح ملف صورة حالة قبل تأكيد الموافقة الخطية.

## تصميم — Canva

توليد منشورات، كاروسيل، عروض. المخرَج **مسوّدة تصميم** تُراجَع، لا نشر.

## إعلانات — Meta Ads · Windsor.ai

- **قراءة الأرقام:** حرة (أداء الحملات، الجمهور، التكلفة).
- **أي تغيير** (إنشاء حملة، تعديل ميزانية، إيقاف/تشغيل): يُعرض كاقتراح مكتوب أولاً، ولا يُنفَّذ إلا بموافقة صريحة في نفس المحادثة.
- كل مخرَج إعلاني ينتهي بسطر: «تحقق تنظيمي مطلوب قبل الإطلاق (CST / اشتراطات الإعلان الصحي)».

## محادثات — ChatPlace

انستغرام حالياً، وواتساب عند ربطه. يقرأ المحادثات غير المردودة، يقترح ردوداً. **الرد يُقترح ولا يُرسل** إلا بموافقة.
لا يُنسخ اسم عميل ولا رقمه في أي مخرَج.

## بحث — WebSearch · WebFetch

لأي معلومة قابلة للتغير (أسعار، أنظمة، دراسات، منافسين). كل ادعاء علمي يحتاج مصدراً منشوراً — وإلا يُصاغ كرأي سريري.

لا تُستخدم أدوات أخرى (curl، سكربتات) لجلب محتوى رفضته أدوات الويب.

## مستندات — docx · xlsx · pptx · pdf

للمخرجات النهائية الجاهزة للاستخدام. المهارة المناسبة تُقرأ **بعد** جمع المحتوى لا قبله.

## قاعدة عامة

أي أداة تُغيّر شيئاً في العالم الخارجي (ترسل، تنشر، تصرف مالاً، تحذف) — **الافتراضي مسوّدة/اقتراح**، والتنفيذ بموافقة صريحة.
