# قوالب ملفات المعرفة

## ١. الخدمات والأسعار

```markdown
# خدمات العيادة والأسعار

| | |
|---|---|
| يستخدمه | مساعد الردود · مساعد العروض · مساعد المحتوى |
| المصدر | الطبيب/ة مباشرة |
| آخر تحديث | 2026-08-21 |
| يحتاج مراجعة | عند أي تغيير سعر |
| حساسية | داخلي |

| الخدمة | الوصف بلغة المريض | النطاق السعري | الجلسات | ملاحظات |
|---|---|---|---|---|
| فينير خزفي | ... | ... | ... | السعر يُذكر كنطاق لا كرقم نهائي |

**قاعدة:** لا يُعطى سعر نهائي قبل الكشف. تُذكر النطاقات فقط، مع أن الخطة النهائية تحدَّد بعد الفحص والأشعة.
```

## ٢. بروتوكول سريري

```markdown
# بروتوكول: ⟨الإجراء⟩

| | |
|---|---|
| يستخدمه | ... |
| المصدر | ⟨مرجع منشور / ممارسة العيادة⟩ |
| آخر تحديث | ... |
| حساسية | داخلي |

## دواعي الاستخدام
## موانع الاستخدام
## الخطوات
## ما يُقال للمريض
## المخاطر والبدائل
## المصادر
- ⟨مرجع كامل⟩ — أو «ممارسة عيادة، غير مدعوم بمرجع منشور»
```

الادعاء بلا مصدر يُوسم صراحة كممارسة لا كدليل.

## ٣. الأسئلة المتكررة

```markdown
# أسئلة المرضى المتكررة

| السؤال كما يُسأل | الرد المعتمد | حد لا يُتجاوز |
|---|---|---|
| «كم يصير ألم؟» | ... | لا وعد بانعدام الألم |
| «كم تدوم؟» | ... | لا ضمان مدة |
```

عمود «حد لا يُتجاوز» إلزامي في هذا القالب.

## ٤. ملف منافس / سوق

```markdown
# ⟨الحساب / العيادة⟩

| | |
|---|---|
| المصدر | ملاحظة عامة — تاريخ الجلب: ... |
| حساسية | داخلي |

## التموضع
## ما ينجح لديهم ولماذا
## الفجوة التي يتركونها
```

ملاحظات على المحتوى العام فقط. لا استنتاجات عن أشخاص، ولا استخدام هذه الملفات في محتوى يقارن الطبيب/ة بأطباء آخرين — المقارنة ممنوعة في الإعلان الصحي.

## ٥. قاعدة التجهيل — قبل حفظ أي شيء من ملف مريض

| يُحذف نهائياً | يُستبدل |
|---|---|
| الاسم، رقم الملف، الجوال، البريد، الهوية | «حالة ١» |
| تاريخ الميلاد | فئة عمرية عشرية: «٣٠–٤٠» |
| تواريخ المواعيد الدقيقة | «الجلسة الأولى / بعد ٦ أسابيع» |
| صور تُظهر الوجه أو علامة مميزة | لا تُحفظ في قاعدة المعرفة إطلاقاً |
| اسم جهة العمل أو أي تفصيل يُعرّف | يُحذف |

بعد التجهيل اسأل نفسك: **هل يستطيع أحد من العيادة معرفة من هذا؟** إن كان الجواب نعم أو ربما — لا يُحفظ.
