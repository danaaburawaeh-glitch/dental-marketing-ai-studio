## حقول الدليل — التعريف

| الحقل | المطلوب |
|---|---|
| المساعد | الاسم المعروض بالعربية + الاسم التقني بين قوسين |
| المهمة | سطر واحد. إن احتاج سطرين، المساعد يفعل أكثر من اللازم |
| يشتغل عند | عبارتان إلى ثلاث، منقولة حرفياً من وصف المهارة |
| الأدوات | الموصّلات المستخدمة فقط |
| المعرفة | مسار داخل `knowledge/`، أو `—` |
| الإصدار | `metadata.version` من المهارة |
| آخر تحديث | تاريخ آخر تعديل جوهري |
